# Adobe Spectrum — loading / empty / error states (domain 15)

Status: **ANSWERED for errors, thin for loading, silent for empty.** `/content/writing-for-errors` as a
*page* is a 22 B shell; the markdown twin (`s2-docs/content/writing-for-errors.md`, 28,176 B) was

finding: their silence is the finding, not our gap.
