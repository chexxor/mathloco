# Adobe Spectrum — focus & keyboard (domain 8)

Status: **ANSWERED at the component level, and this is where this system is furthest ahead of ours:**
it declares keyboard support *per component* (a states table) and declares accessibility semantics in a
schema, which is a machine-readable surface our system has no equivalent of. What it never prints is the
ring's geometry.

| id | claim | kind | locator | quote | enforcement in source |
|---|---|---|---|---|---|
| S8-focus-01 | Focus is one of four **user-initiated states** in a named progression, so it is a state, not an afterthought. | rule | `https://raw.githubusercontent.com/adobe/spectrum-design-data/main/docs/s2-docs/foundations/behavior/states.md` | "A change in color is the primary way that a state is communicated. Colors follow a standard progression for user-initiated states: default, hover, down, and keyboard focus." | none stated |
