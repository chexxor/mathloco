# Adobe Spectrum — forms & validation (domain 10)

Status: **PARTIAL, and flagged at the top: this domain is a draft for us, not a ratified gap.** mathloco
ships no form controls (`grep -rlE '<input|<form|<select|<textarea|required=' src` → one hit, an image
filename inside a comment at `src/components/HorizonBand.astro:74`), so any GAP row built on this file
goes into the titled "pre-loading decisions" section of `GAP-ANALYSIS.md`, never into the ranked ≤25.
The system itself answers validation as a **design** problem (avoid the error) rather than a form-library
problem, which is the shape worth copying.
