| S5-elev-01 | Elevation is expressed as **named styles with a purpose**, not as a numeric level: the set is small and each member has one job. | rule | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "Spectrum provides a range of drop shadow styles that communicate elevation, create visual separation, and emphasize important interface elements. | S5-elev-02 | The primary meaning of a shadow is spatial: content above other content. | rule | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "Use drop shadows to indicate when content appears above other content." | none stated |
| S5-elev-03 | Emphasis is a *second* use of the same device, gated by sparseness — the same gate our system puts on one floating element per page. | rule | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "Drop shadows can also be used to emphasize important interface elements. When applied sparingly, they help guide attention while maintaining a clear and consistent visual hierarchy." | none stated |
| S5-elev-04 | Four named roles, each with a trigger: emphasized-default, emphasized-**hover** (whole container is interactive), elevated (floats on content), dragged. | token | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "If a whole container is interactive, such as in a select box, the drop shadow becomes emphasized-hover on hover." | role names are tokens in the design-data corpus; the trigger is prose |
| S5-elev-05 | Containers are **flat by default**; the shadow appears when the object is lifted — the default state is the negative of what most UIs assume. | behavior | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "Containers don't use drop shadows by default. | S5-elev-06 | A shadow is three composited layers, which is why a single `0 2px 4px` shortcut is not equivalent to their style. | token | `https://spectrum.adobe.com/foundations/styles/object-styles/drop-shadow` | "Spectrum drop shadows are composed of three layers that work together to create a natural sense of depth while preserving the shape of the component." | none stated |
| S5-elev-07 | Depth can be carried by a **background layer** as well as a shadow: elevated = gray-25 plus a drop shadow, and it is used sparingly. | behavior | `https://spectrum.adobe.com/foundations/color/background-layers` | "Elevated backgrounds create the illusion of depth through the use of a drop shadow, and display content that appears on top of other content. | S5-elev-08 | Elevation and colour are the two emphasis devices, and the system says they must be weighed together. | rule | `https://raw.githubusercontent.com/adobe/spectrum-design-data/main/docs/s2-docs/foundations/attention-hierarchy.md` | "both high-contrast colors and elevation communicate specific meanings and add emphasis within pages and flows — and these are both used very thoughtfully." | none stated |
| S5-elev-09 | High-attention devices are rationed by a stated failure mode, not by a count: too many at once is noisy. | rule | `https://raw.githubusercontent.com/adobe/spectrum-design-data/main/docs/s2-docs/foundations/attention-hierarchy.md` | "High attention elements should be used sparingly and selectively.
