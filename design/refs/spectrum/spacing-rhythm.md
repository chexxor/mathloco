# Adobe Spectrum — spacing & rhythm (domain 3)

Status: **ANSWERED, and this is the most transferable domain in the corpus.** Three named scales
(layout / component / container-level), each a geometric progression, each with a written reason for
being geometric. The absence we compare against — a single fixed grid — is argued against *on the page*,
with the perceptual failure named ("72 px and 80 px"), which is exactly the argument our own 1.35/3.0/4.5
scale would have to survive.

| S3-space-01 | Spacing is a **relation**, not a decoration: proximity is the thing that carries meaning. | rule | `https://spectrum.adobe.com/foundations/layout-and-structure/spacing/overview` | "Spacing communicates structure and relationships. When spacing is done well, an interface becomes immediately understandable." | none stated |
