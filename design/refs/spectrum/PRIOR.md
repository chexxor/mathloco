# Adobe Spectrum — PRIOR.md (quarantine)

Anything we know about Adobe Spectrum **without a locator on a URL fetched this session** goes here.
Everything in this file is marked `UNGROUNDED — NOT ELIGIBLE FOR GAP ANALYSIS`: it may point at where to
look, and it may not be quoted, counted, ranked, or cited in `GAP-ANALYSIS.md`. This system needs this
file more than the others do, because the site is a client-side-rendered shell: a large share of what a
browser shows a visitor is not in anything we fetched, and the difference between "we didn't bother" and
"we can't reach it" is exactly what this file records.
