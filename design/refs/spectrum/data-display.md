# Adobe Spectrum — data display (tables, lists, empty states) (domain 12)

Status: **ANSWERED for tables and cards at the component level; the empty case is where it stops.**
We ship no HTML tables (`grep -rlE '<table' src` → 0 files), so the ranked rows in `GAP-ANALYSIS.md` will
take only the transferable *density/quiet/overflow* principles from this file; the rest goes to the
pre-loading section.
